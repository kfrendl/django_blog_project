## Electric Ink - Full-Stack Blog Platform

This is a modern, full-featured blog application built with Django (Backend) and React (Frontend). The project aims to provide a secure, dynamic, and responsive platform where users can publish posts and interact with one another.

<p align="center">
<img src=".\documentation\screenshots\home_page.png" alt="Main Page" width="60%">
</p>

### Key Features

- **Full CRUD Operations:** Create, Read, Update, and Delete posts and comments with ease.

- **JWT Authentication:** Secure user registration and login system powered by JSON Web Tokens.

- **Interactive Liking System:** Dynamic like and unlike functionality for posts without page reloads, ensuring a smooth SPA experience.

- **Role-Based Access Control (RBAC):** Strict server-side permission verification—only the original author or an administrator can modify or delete content.

- **Responsive Design:** A sleek, modern user interface built with Tailwind CSS, fully optimized for both desktop and mobile devices.

- **Administration Interface:** Integration with the built-in Django Admin panel for streamlined content and user moderation.

### Installation and Setup

#### Backend Setup

```
cd backend
python -m venv venv
venv\Scripts\activate # On Mac: source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

#### Frontend Setup

```
cd frontend
npm install
npm start
```

### API Endpoints Summary

| Module | Endpoint | Method | Description |
| :--- | :--- | :--- | :--- |
| **Authentication** | `/api/token/` | `POST` | Login (Obtain Access & Refresh tokens) |
| **Authentication** | `/api/register/` | `POST` | Create a new user account |
| **Profile** | `/api/user/me/` | `GET` | Retrieve the authenticated user's details |
| **Posts** | `/api/posts/` | `GET` | List all blog posts |
| **Posts** | `/api/posts/` | `POST` | Create a new blog post |
| **Posts** | `/api/posts/{id}/` | `GET` | Retrieve a specific post by ID |
| **Posts** | `/api/posts/{id}/` | `PUT` | Update a post (Author or Admin only) |
| **Posts** | `/api/posts/{id}/` | `DELETE` | Permanently delete a post (Author or Admin only) |
| **Comments** | `/api/comments/` | `GET` | List all comments |
| **Comments** | `/api/comments/` | `POST` | Create a new comment for a specific post |
| **Comments** | `/api/comments/{id}/` | `DELETE` | Delete a comment (Author or Admin only) |
| **Likes** | `/api/likes/` | `POST` | Like a specific post |
| **Likes** | `/api/likes/?post={id}` | `GET` | Retrieve the user's specific Like ID for unliking |
| **Likes** | `/api/likes/{id}/` | `DELETE` | Remove a like (Unlike) |
